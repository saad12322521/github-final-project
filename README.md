# Simple Interest Calculator

A simple interest calculator that computes the interest earned or owed on a
principal amount over a given period of time, at a fixed annual interest rate.

## What is Simple Interest?

Simple interest is calculated using the formula:

```
SI = (P × R × T) / 100
```

Where:
- **P** = Principal amount (the initial sum of money)
- **R** = Rate of interest (per year, in percentage)
- **T** = Time period (in years)
- **SI** = Simple Interest

The **Total Amount** payable/receivable after the time period is:

```
Total Amount = P + SI
```

## Features

- Takes principal, rate of interest, and time as input
- Calculates the simple interest using the standard formula
- Displays both the interest earned and the total amount
- Simple, beginner-friendly logic — great for learning basic
  arithmetic operations and user input handling in code

## Example

| Principal (P) | Rate (R) | Time (T) | Simple Interest | Total Amount |
|----------------|----------|----------|------------------|---------------|
| 1000           | 5%       | 2 years  | 100              | 1100          |

Calculation:
```
SI = (1000 × 5 × 2) / 100 = 100
Total Amount = 1000 + 100 = 1100
```

## How to Use

1. Clone this repository
2. Open the calculator file
3. Enter the principal amount, rate of interest, and time period when prompted
4. View the calculated simple interest and total amount
